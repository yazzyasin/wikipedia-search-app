# Wikipedia Search App

A simple web app that lets users search Wikipedia and view results instantly.

## Live Demo
[Open the app](https://your-live-link.com)

## Features
- Search any topic using a keyword
- Fetches results in real time from the Wikipedia API
- Shows the title, a short description, and a link to the full article
- Responsive layout that works on mobile and desktop

## Tech Stack
- HTML
- CSS
- JavaScript (Fetch API)
- Tailwind CSS

## How to Run Locally
1. Clone the repository:
   `git clone https://github.com/yazzyasin/wikipedia-search-app.git`
2. Open the project folder.
3. Open `index.html` in your browser.

## What I Learned
- Fetching data from a public API using JavaScript
- Updating the page dynamically with search results
- Building a responsive UI with Tailwind CSS
